# Furniture Timer

Небольшое окно поверх всех окон: считает время проектирования мебели и стоимость по часовой ставке. Работает без сети и без прав администратора.

## Что делает

- **Старт / Пауза / Стоп.** Секундомер идёт только в рабочем состоянии. Стоп записывает сессию и обнуляет таймер. При следующем запуске программы незавершённая сессия не продолжается.
- **Простой.** На Windows простой системы определяется через `GetLastInputInfo`. По умолчанию порог — 5 минут (настраивается). Когда порог достигнут, таймер ставится на паузу задним числом, с момента начала простоя, и появляется окно:
  - **Оставить** — простой записывается, таймер остаётся на паузе;
  - **Продолжить** — простой записывается, таймер снова идёт;
  - **Отбросить простой** — эти секунды не попадают ни в работу, ни в простой.
- **Стоимость.** На экране сразу видно `ставка · стоимость`. Стоимость = активные часы × ставка на момент остановки. Ставка и валюта сохраняются в строке сессии.
- **Проект.** В окне можно указать номер проекта, название и клиента. Подсказки берутся из уже сохранённых сессий.
- **История.** Последние сессии, итог по проекту и выгрузка в CSV.
- **Трей.** Крестик прячет окно в трей. Меню трея: показать, старт/пауза, выход.
- **Язык.** Английский и русский. Пока язык не выбран в настройках, берётся язык системы.

Данные лежат в `%APPDATA%\FurnitureTimer\db.sqlite`, лог — в `%APPDATA%\FurnitureTimer\logs\app.log`.

Настройки по умолчанию: ставка `0`, валюта `₽`, порог простоя `300` секунд.

## Запуск из исходников

Нужен Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\furniture-timer.exe
```

То же через модуль:

```powershell
.\.venv\Scripts\python.exe -m furniture_timer
```

На macOS и Linux простой определяется через `pynput` (ставится автоматически вне Windows):

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/furniture-timer
```

## Сборка exe

Windows, один файл без консоли:

```powershell
.\build.ps1
.\dist\FurnitureTimer.exe
```

На macOS и Linux:

```bash
./build.sh
./dist/FurnitureTimer
```
